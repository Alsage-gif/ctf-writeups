## Стабилизация оболочки

Полученная оболочка была неудобной: отсутствовал нормальный TTY. Стабилизировал её так:

```bash
python3 -c 'import pty; pty.spawn("/bin/bash")'
```

После этого нажал `Ctrl+Z`, выполнил `stty raw -echo; fg` и установил тип терминала:

```bash
export TERM=xterm
```

![Стабилизированная интерактивная оболочка](../images/Pasted%20image%2020260329174814.png)

## Итог

В этой части прохождения я:

1. обнаружил Apache и Pluck 4.7.13;
2. получил web-shell через загруженный `shell.phar`;
3. стабилизировал reverse shell;
4. проверил PwnKit, cron, SUID и capabilities;
5. исследовал файлы приложения и домашние каталоги пользователей;
6. подтвердил рабочие учётные данные пользователя `lucien`.

Главный урок — не зацикливаться на одном эксплойте. Если PwnKit, cron и SUID не дают результата, нужно вернуться к веб-приложению, конфигурации и файлам пользователей. При этом в write-up важно фиксировать точный источник найденного пароля: в исходных заметках этот шаг пока не восстановлен.
