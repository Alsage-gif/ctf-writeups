## Извлечение данных из изображения

Для проверки стеганографии использовал `stegseek` и словарь `rockyou.txt`:

```bash
stegseek image.jpg /usr/share/wordlists/rockyou.txt
```

`stegseek` предназначен для извлечения данных, скрытых с помощью `steghide`, и подбора passphrase. В отличие от ручного запуска `steghide`, он автоматически проверяет словарь и извлекает найденный файл.
